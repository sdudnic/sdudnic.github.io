# Ocupația personajelor

Ocupația descrie munca sau activitatea personajului: cioban, grădinar, negustor, soldat, slujitor ori altă îndeletnicire indicată. Un titlu de rang nu se transformă automat într-o profesie.

Se notează ce face personajul, pentru cine lucrează, cum este plătit și ce pricepere îi este recunoscută. Sarcinile ocazionale se deosebesc de o ocupație stabilă.

În povestea fetei harnice, îngrijirea animalelor și lucrurilor este esențială pentru relațiile de ajutor. Acțiunile permit analiza muncii fără a-i atribui fetei o profesie pe care textul nu o numește.

Între epoci s-ar compara prestigiul muncii, corectitudinea plății și raportul dintre competență și răsplată. Ocupația nu stabilește etnia ori valoarea morală.
